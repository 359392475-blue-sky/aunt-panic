# PRD —— 二舅妈急了

> 产品需求文档（Demo 级 / 个人项目）
> 最后更新：2026/05/01

---

## 一、产品定位

**一句话**：把家族群假消息一键反转成"伪权威辟谣"长图，让长辈在群里收到立场相反的同款文章，体验被假信息包围的荒谬。

**项目代号**：二舅妈急了（**仅作者与粉丝间使用，不出现在生成内容里**——长图、文章正文、警示语都不允许出现"二舅妈急了"字样，避免冒犯长辈）

**项目性质**：作者个人 Demo 项目，覆盖作者本人 + 200-300 名粉丝小范围使用。

---

## 二、问题描述

家族群中长辈们经常转发未经核实的假消息（养生谣言、社会事件谣言、阴谋论等）。这些信息有共同特征：
- 标题党、情绪化
- 假托权威（"专家说"、"央视报道"）
- 缺乏来源
- 配图配视频增加可信度

直接反驳常导致家庭矛盾。本产品通过 **以毒攻毒** 的反讽手法，让长辈在自己亲眼看到立场完全相反的"同款假权威"长图时，产生认知冲击，从而培养：
- 信息核实意识
- 独立思考能力

|---|---|---|

## 四、核心使用流程

```
用户(年轻人)在手机上:
  ① 在微信里看到长辈转发的假消息文章/链接
  ② 点开 → 复制文章链接
  ③ 打开"二舅妈急了" H5（移动网页）
  ④ 粘贴链接到输入框，点"开始反讽"
  ⑤ 等待 10-30 秒（解析→反转→渲染长图）
  ⑥ 在 H5 上预览生成的反讽长图（顶部 AI 声明 + 红章封面 + 反转正文 + 底部红色警示语）
  ⑦ 点"保存长图"按钮
  ⑧ 长按图片→选择"保存到相册"（iOS Safari/Android Chrome 通用）
  ⑨ Toast 提示："图片已就绪，长按保存后发到家族群"
  ⑩ 切到微信→进家族群→相册选图→发送
  ✅ 群里收到一张和长辈日常发的"养生长图"形态完全一致，但立场相反的反讽长图
```

**全流程移动端完成，不考虑 PC 端。**

## 五、产品要求清单

### 要求 1：分发形态 = 长图（不是链接、不是卡片）
- 后端用 Playwright 渲染 HTML 为 PNG 长图
- 用户在 H5 长按图片可保存到相册
- 进了相册后，跟相册里任何其他养生图体验一致——发到家族群即原生显示
- **理由**：所有非微信公众号链接进群都降级为弱预览；长图反而是长辈最熟悉的形态，反讽张力更强，且零审核成本

### 要求 2：移动端 H5 一键流程
- 形态：移动端 H5（响应式）
- 不做 PC 适配
- 关键交互：粘贴 → 等待 → 预览 → 保存 → 转发，**5 步完成**

### 要求 3：缩略图叠加红色辟谣图章
- 抓原文 og:image，叠加预制的"专家已辟谣"红色图章 PNG
- 图章斜向 -15°，覆盖右下角约 35% 面积
- 合成图作为长图首屏的封面区

### 要求 4：底部固定红色警示语
所有长图正文末尾必须追加（**原文不可改**）：

> **AI 时代，制造错误虚假信息，有手就行（我也可以），请家人们保持独立思考，不要轻信网络劣质内容，核实信息来源，不传谣不信谣。**

样式：红色 H3 字号，居中，不可被去除。

### 要求 5：纯移动端闭环
- 不开发 PC 版本
- iOS Safari + Android Chrome 为主要适配目标
- 微信内置浏览器为次要兼容目标

### 要求 6：原文图文位置 + 文风保留，仅反转关键结论
AI 生成的反向版本需遵守：
- ✅ **保留**原文段落结构（段落数量、顺序）
- ✅ **保留**原文图片（按原顺序原位嵌入，**不做任何改动**）
- ✅ **保留**原文视频（占位文本提示原位置）
- ✅ **保留**原文文风（词汇、感叹号、emoji 使用频率）
- ❌ **反转**关键结论（核心观点完全相反）
- ❌ **反转**关键论据（围绕新结论重新论证）
- ❌ **反转**标题（保留耸动风格但立场相反，**且避开微信标题党红线词**）

### 要求 7：长图视觉风格
- 与原文版式追求一致：**段落 + 图片位置严格对齐原文**
- 整体阅读样式 = 通用图文长卷（接近公众号文章页/知乎专栏的常见排版），**不逐像素复刻原站 CSS**——原 CSS 远程加载不稳，且常常不如通用样式好看
- 长图里**不出现项目品牌名**

### 要求 8：保存图片体验
- 用户点"保存长图"按钮
- 优先用 Web Share API（iOS 17+ / Android Chrome）调起系统分享面板，含"保存到相册"选项
- 兜底：弹大图 + 文字引导"长按图片保存到相册"
- 1.5 秒后 toast：「图片已就绪，长按保存后发到家族群」
- 浏览器无 API 监听用户实际保存动作，toast 是行为引导而非结果回调

## 六、MVP 功能范围

### P0（必做）
- [ ] 移动 H5：链接粘贴页 / 等待页 / 结果预览页
- [ ] 后端：原文链接解析（保留段落节点：文字/图片/视频按原顺序）
- [ ] 后端：DeepSeek 反讽生成（仅反转文字段，图片视频原位回填）
- [ ] 后端：缩略图水印合成（原 og:image + 红章）
- [ ] 后端：HTML 重写器（拼装含警示语的完整 HTML）
- [ ] 后端：Playwright 长图渲染
- [ ] 后端：本地图床（落盘 + 7 天自动清理）
- [ ] H5：保存图片引导（Web Share API + 长按兜底 + toast）
- [ ] 强制水印：缩略图红章 + 底部警示语 + 头部 AI 声明
- [ ] 后端硬拦截：医疗具名 / 政治人物 / 金融产品 / 色情暴力

- [ ] 长图分享前编辑（用户微调标题或某段文字）

### P2（暂不做）
- [ ] 用户登录系统
- [ ] 付费 / 配额
- [ ] 浏览器插件
- [ ] 小程序版本

## 七、非功能需求

| 维度 | 指标 |
|---|---|
| 响应速度 | 端到端 ≤ 30 秒（解析 5s + LLM 15s + 渲染 5s）|
| 可用性 | Demo 级，单点部署即可 |
| 并发 | 同时在线 ≤ 10 人 |
| 成本 | 月度运营成本 < ¥100（DeepSeek + 服务器，无公众号认证费）|
| 安全 | HTTPS、不持久化原文全文、API key 走环境变量 |
| 隐私 | 不收集用户信息、不做数据分析、生成图片 7 天后自动清理 |

## 八、伦理与边界（不可妥协）

1. **强制视觉标识**：红章水印 + 红色警示语 + 头部 AI 声明，三处不可关闭
2. **领域禁区**：医疗具名、政治、金融、色情暴力 → 后端拒答，返回元层次反讽模板
3. **使用场景声明**：H5 首屏明示"仅供个人媒介素养训练，请勿用于其他用途"
4. **不做大规模分发**：不做 SEO、不做付费推广、仅作者私域使用
5. **AIGC 强制标识合规**：长图头部 + 文件元数据双重 AI 标识（《人工智能生成合成内容标识办法》2025/9/1 实施）
6. **不出现品牌名**：长图、警示语、AI 声明里都不出现"二舅妈急了"

## 十、不做的事（明确边界）

- ❌ 不做微信公众号自动发布（API 已对未认证号关闭，且认证门槛与本项目规模不匹配）
- ❌ 不做大规模商业化
- ❌ 不做 PC 端
- ❌ 不做小程序（封禁风险高）
- ❌ 不做用户系统、付费、配额
- ❌ 不做多模型混合（DeepSeek 一个搞定）
- ❌ 不引入 React Native / Flutter（H5 足够）
- ❌ 不在长图中出现项目品牌名"二舅妈急了"
