## 一、技术栈总览

```
前端：Next.js 14 (App Router) + Tailwind CSS + TypeScript（待实现）
后端：Python 3.11 + FastAPI + Uvicorn
图像处理：Pillow（红章水印）+ Playwright（长图渲染）
AI 调用：DeepSeek（OpenAI 兼容接口）
分发：本地图床 → 用户保存图片到相册 → 转发家族群（不依赖任何第三方平台）
存储：本地 SQLite（任务表）+ 本地文件系统（图床）
部署：前端 Vercel；后端 自有服务器（需要 Playwright headless chromium）
```

**v0.2 改动**：移除微信公众号 freepublish 方案（API 政策对未认证号关闭、认证门槛与本项目规模不匹配），改为生成长图 PNG 由用户保存到相册转发。

## 三、模块职责

### 3.1 前端（移动 H5，待实现）

| 路由 | 职责 |
|---|---|
| `/` | 粘贴链接框、"开始反讽"按钮、伦理声明、品牌名（仅前端可见） |
| `/生成中` | 轮询 `/api/status/:id`，进度条 |
| `/结果/:id` | 长图预览（直接显示后端返回的 image_url）+ "保存长图"按钮 + Toast |
| `/关于` | 项目定位、伦理声明 |

**保存交互**：优先调 `navigator.share({ files: [...] })`（iOS 17+ / Android Chrome），兜底是 `<img>` 长按 + 文字引导，1.5 秒后 toast「图片已就绪」。

### 3.2 后端

#### 路由层（薄）
- `生成.py` `POST /api/generate { url }` → `{ task_id, status }`
- `状态.py` `GET /api/status/:id` → `{ task_id, status, progress, image_url, error }`
- `健康检查.py` `GET /health`

#### 业务模块
- **链接解析器**：trafilatura 抽元数据 + BeautifulSoup 找正文容器 → 输出 `段落节点[]`（每个节点带 序号 / 类型 / 内容），保证文字与图片视频按原顺序
- **安全过滤器**：四大禁区词库（医疗 / 政治 / 金融 / 色暴）+ 正则；命中即不调 LLM，返回元反讽模板
- **风格分类器**：关键词启发式分到 `严肃科普 / 爆款震惊 / 长辈图文`（仅参考字段，本期不强用）
- **内容反转器**：调 DeepSeek，仅反转文字段；按序号回填到原段落节点序列，输出扁平 `段落[]`
- **提示词模板**：system 提示词约束（不出现禁词、序号严格对齐、立场反转）+ user 提示词构造（带编号的段落清单）
- **警示语注入器**：提供 `头部声明HTML()` `底部警示HTML()` 两个公开函数，HTML 重写器调用
- **水印合成器**：`Pillow.open(原 og:image) → resize(900×500) → alpha_composite(红章 PNG, -15°) → save(JPEG 90)`；红章 PNG 缺失时现场绘制
- **HTML 重写器**：把封面（base64 data URL 内嵌）+ 头部声明 + 标题 + 段落 + 底部警示拼成完整 HTML，用项目自带通用阅读 CSS
- **长图渲染器**：Playwright chromium headless 加载 HTML → `screenshot(full_page=True, type='png')` → 落盘
- **pipeline.py**：编排上述模块，写入任务状态到缓存

#### 服务层
- `LLMProvider` 协议：`生成(system, user, *, temperature, response_format)` → `str`
- `缓存.py`：`task` 表（task_id, url_hash, url, status, progress, image_url, image_path, error）
- `图床.py`：`入库(图片路径) → (本地路径, 公网URL)`、`清理过期(保留天数)`

#### 配置层
- `settings.py`：DeepSeek key/url/model、app host/port/public_base_url、image_store_dir、image_retain_days、longimage_width/device_scale
- 严禁硬编码任何 key

## 五、关键流程时序

```
[用户在 H5 粘贴 URL]
         │
         ▼
POST /api/generate { url }
         │
         ▼
[后端] 写入 task，立即返回 task_id；后台异步执行 pipeline:
        ① 链接解析器     fetch + 抽段落节点
        ② 安全过滤器     检查禁区
        ③ 内容反转器     调 DeepSeek + 段落对齐合并
        ④ 水印合成器     原 og:image 叠红章 → JPEG
        ⑤ HTML重写器     封面(data URL) + 警示语 + 段落 → 完整 HTML
        ⑥ 长图渲染器     Playwright 截全屏 → PNG
        ⑦ 图床           落盘 → 公网 URL
        ⑧ 缓存写入 status=done, image_url
                │
[H5] 轮询 /api/status/:id ──→ done
                │
                ▼
跳转 /结果/:id，<img src={image_url} />
                │
                ▼
用户点"保存长图"
   ├ Web Share API → 系统分享面板含"保存图像"
   └ 兜底：长按图片保存到相册
                │
                ▼
微信 → 家族群 → + → 相册 → 选这张 → 发送
                │
                ▼
[家族群] 反讽长图原生显示 ✅
```
