- 完全免费、无注册、无审核、无平台依赖

## 〇、项目核心定位

把"二舅妈"在家族群转发的假消息（X）作为输入，输出**风格相同、立场完全相反、形态以微信小卡片呈现**的反讽内容（¬X），用以反讽并教育受众。

**项目本质不是 AI 文本生成，而是"让 AI 生成的反讽内容以微信原生小卡片形态出现在家族群"。** AI 是手段，分发渠道才是关卡。

**规模设定**：200-300 人 Demo 级，作者本人公众号承载，不追求大规模商用。

## 二、微信小卡片机制（修正版）

微信群里能显示富卡片的 URL，实际上有 **三条机制并存**：

### 2.1 大厂白名单域名（用户观察到的现象）
微信对一批知名平台做了特殊抓取适配：知乎、B 站、小红书、淘宝、高德、抖音 web、微博等。这些域名的链接粘贴到群里，**无需任何配置**就有完整卡片预览。

但白名单是**封闭的**，普通开发者无法申请加入。本项目进不去。

### 2.2 微信自家 `mp.weixin.qq.com`（本项目主路径）
微信识别自家域名，公众号文章 URL 直接渲染为完整卡片：标题、封面图、摘要、公众号 logo。**这是本项目唯一可行的"自动卡片"路径**。

### 2.3 第三方 H5 + JS-SDK + 备案（兜底）
在已备案 + 已配置 JS 安全域名的 H5 内调用 `wx.config` + `wx.updateAppMessageShareData`，可以在用户主动点击"发送给朋友"时让微信使用我们指定的卡片内容。但**裸链接粘贴到群里**多半降级为弱预览，不是富卡片。

## 三、本项目分发方案：自有公众号 + API 闭环

利用作者已有的认证公众号（200-300 人粉丝足够覆盖），调用公众号 API 自动发布反讽文章，拿到 `mp.weixin.qq.com/s/xxx` 短链，用户在 H5 上长按或调起微信即可转发。

### API 调用顺序
1. `cgi-bin/token` 获取 access_token（每 2h 刷新，需 IP 白名单）
2. `cgi-bin/material/add_material` 上传水印缩略图为永久素材，拿到 `thumb_media_id`
3. `cgi-bin/draft/add` 新建草稿（标题、作者、digest、content HTML、thumb_media_id）
4. `cgi-bin/freepublish/submit` 发布草稿，返回 `publish_id`
5. `cgi-bin/freepublish/get` 轮询发布状态，拿到 `article_url`
6. 短链返回前端 H5

### 仍需关注的点
- 公众号对反讽医疗/养生/食品类内容审核较严，**首批 PoC 务必跑过 5-10 条不同主题**测过审率
- access_token IP 白名单需在公众号后台预先配置生产环境出口 IP
- `freepublish` 不计入"群发"额度，但单日发布条数仍有上限，**实测**

## 四、缩略图水印技术方案

### 流程
1. 后端从原文章 URL 抓取 OG image（绕开 CORS）
2. 用 Pillow 加载原图，缩放到目标尺寸（公众号封面建议 900×500，2.35:1）
3. 叠加预制好的"专家已辟谣"红色图章 PNG（透明背景，斜向 -15°，覆盖右下约 30% 面积）
4. 输出 JPEG（质量 90），上传到公众号素材库

### 技术细节
- 红章 PNG 模板预制好，不要每次实时生成（保证视觉一致性）
- 同一原文 URL 的合成结果缓存（用原文 URL hash 做 key）
- 原文无 OG image 时降级用项目 logo + 标题文字渲染

### 不可行的方案
- 前端 Canvas 合成不可行——blob 转 base64 上传公众号素材库会失败
- CDN 实时图片处理服务不可行——签名后无法稳定上传到素材库

## 五、AI 模型与提示词工程

### 模型选择
- **主模型**：DeepSeek V4（最新版，用户提供 API Key）
  - 中文反讽自然，价格低，对"假权威"风格容忍度高
  - 单次请求成本预计 ¥0.01 - 0.05 之间
- **备用**：Claude（仅在 DeepSeek 输出质量不达标时调试用，不接入生产）

### 提示词工程要点
- 输入必须是结构化 JSON：`{ title, paragraphs:[{type, content}], images:[url], videos:[url], key_claim }`
- 输出必须维持原文段落数、图片视频位置不变（用户要求 6）
- 仅替换 `key_claim` 及其论证段落
- 标题需重新生成（保留耸动风格但反转立场）

### 风格库
预制 3 套风格模板，按原文风格自动选用：
- **严肃科普风**："据《xx医学杂志》最新研究"
- **爆款震惊风**："央视紧急曝光！xxx 千万别再做了！"
- **长辈图文风**：多 emoji + "转给家人朋友看看吧"

## 六、伦理与合规护栏

### 强制设计要求（写入 PRD 不可妥协）

#### 底部固定红色警示语（用户要求 4）
> AI 时代，制造错误虚假信息，有手就行（我也可以），请家人们保持独立思考，不要轻信网络劣质内容，核实信息来源，不传谣不信谣。

每篇文章正文末尾自动追加，红色 H3 字号，居中。

#### 缩略图强制水印（用户要求 3）
"专家已辟谣"红色图章，斜向 -15°，覆盖右下角，alpha 0.85。

#### 文章首部反讽声明
正文起首一行灰色小字：
> 【AI 生成 · 反讽辟谣作品 · 与原文立场相反】

### 领域禁区（后端硬拦截）
- 涉及具体药品名称、剂量
- 涉及政治人物、敏感事件
- 涉及金融产品、投资建议
触发禁区时不调 LLM，直接返回元层次反讽模板（"任何宣称'某药能治百病'的文章都值得怀疑"）。

### 数据策略
- 不持久化用户输入的原文全文，仅保留 URL hash 做去重
- 生成结果保留 7 天后自动删除
